# Portal Escola Iêda V2

Protótipo visual isolado da nova geração do `escolaieda.com`.

## Estratégia desta fase

1. validar primeiro uma Home moderna em Astro puro;
2. consolidar componentes e design system;
3. somente depois integrar TinaCMS e `/admin`;
4. manter o site atual intacto até a V2 ser validada.

## Executar

```bash
npm install
npm run dev
```

## Validar

```bash
npm run check
npm run build
```

A integração com TinaCMS não faz parte deste primeiro marco visual.
