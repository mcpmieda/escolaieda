PASSO 187 - CRIAR ATALHO PARA CONTINUAR PROJETO

Data: 2026-05-24

Pedido do usuario:

Criar um atalho na Area de Trabalho para voltar ao projeto de onde parou.
O atalho deve ler o AGENTS e os TXT do SALVAMENTO_AUTOMATICO.
Tambem deve preparar uma abertura do chat com:

"OI GUI, VAMOS VOLTAR AO PROJETO. NOS PARAMOS EM TAL COISA..., O QUE DESEJA FAZER?"

Arquivos criados:

- CONTINUAR_PROJETO_ARQUIVO_DIGITAL.ps1
- SALVAMENTO_AUTOMATICO/PASSO_187_CRIAR_ATALHO_CONTINUAR_PROJETO.txt

Comportamento do script:

- entra na pasta do projeto;
- mostra ultimo commit;
- mostra tag no HEAD, se houver;
- le os ultimos TXT de SALVAMENTO_AUTOMATICO;
- le o ultimo salvamento automatico;
- cria o prompt em prompts_codex/RETOMAR_PROJETO_ARQUIVO_DIGITAL.txt;
- copia o prompt para a area de transferencia;
- mostra na tela o resumo de retomada.

Atalho esperado na Area de Trabalho:

- Arquivo Digital - Continuar Projeto.lnk

Resultado esperado:

Ao abrir o atalho, o usuario tera um prompt pronto para continuar o projeto no Codex/ChatGPT com base no AGENTS e nos TXT salvos.
