# Assets do Arquivo Digital

Esta pasta concentra arquivos visuais usados especificamente pelo sistema Arquivo Digital Escolar.

Estrutura:

`	ext
arquivo-digital/assets/imagens/
arquivo-digital/assets/icones/
`

Regras:

- manter assets específicos do Arquivo Digital dentro de rquivo-digital/assets;
- não depender de imagens soltas fora da pasta rquivo-digital para novas alterações;
- não apagar a pasta raiz imagens/ sem diagnóstico, pois ela pode ser usada por outras páginas do site;
- preferir SVG local para ícones de interface;
- não usar CDN externa para ícones do sistema.
